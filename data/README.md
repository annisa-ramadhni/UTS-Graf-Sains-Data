# Dataset

Dataset yang digunakan dalam tugas UTS Graf Sains Data adalah dataset e-commerce Retailrocket.

Dataset ini digunakan untuk membangun graf interaksi antara Visitor dan Item pada Neo4j, serta melakukan analisis similarity dan rekomendasi item.

## Data yang digunakan

- events.csv: data interaksi visitor dengan item.
- category_tree.csv: struktur kategori item.
- item_properties_part1.csv dan item_properties_part2.csv: properti item.

## Periode analisis

Data interaksi difilter menjadi dua periode, yaitu P1 dan P2, sesuai implementasi pada notebook.

## Sumber dataset

Retailrocket Recommender System Dataset:
https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset
